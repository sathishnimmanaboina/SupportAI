# SupportAI - AI Powered Customer Support System

## Overview

SupportAI is an AI-powered customer support ticket management platform built using Flask and Google Gemini AI. Users can register, log in, create support tickets, and receive AI-generated ticket analysis including summaries, categories, priorities, and suggested responses.

## Features

- User Authentication
- Dashboard
- Ticket Management
- AI Ticket Analysis using Gemini
- Ticket Summary Generation
- Priority Prediction
- Category Classification
- Suggested Customer Response
- Responsive UI
- CI/CD with GitHub Actions
- Vercel Deployment

## Tech Stack

- Python
- Flask
- SQLAlchemy
- SQLite
- Bootstrap
- Google Gemini API
- Git & GitHub
- GitHub Actions
- Vercel
